# Business Admin Dashboard

A modern and fully responsive **Business Admin Dashboard** built with **React**, **Recharts**, and **Framer Motion**.  
This dashboard provides analytics, charts, user management tools, and a clean dark UI inspired by enterprise-grade systems.

The project includes a collapsible sidebar, dynamic charts, user filters, activity feeds, routing between pages, and smooth animations throughout the interface.

---

## ✨ Features

### 🔹 Clean & Modern UI

A professional dark-themed layout with a collapsible sidebar, top navigation bar, and modular card system.

### 🔹 Multi-Page Navigation (React Router)

Includes pages:

- Dashboard
- Users
- Orders
- Settings

### 🔹 Dynamic Data (Mock API)

The dashboard simulates real API requests using a built-in mock backend that returns:

- Stats
- Sales analytics
- Revenue
- Users
- Activity logs

### 🔹 Charts & Analytics

Built with **Recharts**, including:

- Monthly Sales (Line Chart)
- Quarterly Revenue (Bar Chart)

### 🔹 User Management Tools

- Search users (name or country)
- Filter by status (Active, Pending, Inactive)
- Responsive table layout

### 🔹 Activity Feed

Shows recent system actions with categorized indicators (info, warning, success).

### 🔹 Smooth Animations

Powered by **Framer Motion**, enhancing:

- Cards
- Hover effects
- Page transitions

### 🔹 Fully Responsive

Optimized for desktops, tablets, and mobile layouts.
